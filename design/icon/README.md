# App icon drafts

Three original directions in the app's pen-and-wash style, drawn as SVG in `icons.html` and rendered to 1024px PNGs with `render.mjs`:

- `daisy-1024.png` · A, a daisy on a tuft of crayon grass, baby blue
- `blade-1024.png` · B, a bent blade of grass with a small daisy, pink
- `book-1024.png` · C, an open book resting in the grass, soft yellow

Once one is chosen, `python3 scripts/make-icons.py <daisy|blade|book>` writes every size the app uses.
